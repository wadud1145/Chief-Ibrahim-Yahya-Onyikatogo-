HOW TO EDIT THIS WEBSITE

1. Open index.html in any text editor (Notepad, VS Code). Everything you can change is in plain text.
   Look for the comments that say <!-- ... --> to find each section.

2. PHOTOS
   - Put your pictures in the "images" folder (jpg or png).
   - Portrait: change   images/portrait.svg   to your file name, e.g.  images/portrait.jpg
   - Certificates: change each   images/certificate-1.svg   to your file name.
     Each certificate appears twice in index.html (small card + large view). Change both.

3. ADD ANOTHER CERTIFICATE
   Copy one certificate card and one lightbox block, paste them under the last ones,
   and change the number (cert-4) in BOTH the card link (href="#cert-4") and the lightbox (id="cert-4").

4. COLORS
   Open style.css and change the values at the very top (lines starting with --purple, --teal ...).

5. PUT IT ONLINE (GitHub Pages)
   Upload index.html, style.css and the images folder to a public repository named
   yourusername.github.io, then turn on Settings > Pages.
